이 저장소는 GitHub Pages 공개 사이트이고 `AGENTS.md`가 사내 정보 포함을 금지한다. 2026-09-17에 전수 검사해 노출된 식별자를 모두 제거하고 푸시했다.

| 위치 | 내용 | 조치 |
|---|---|---|
| `외부 CDN 의존이 부른 화면 멈춤.md` | 사내 코드베이스 약칭, 사내 파일명 | 일반 표현으로 교체 (`3259327`) |
| `content/개발/git/1. git 원격 동기화 파이프라인.md` | 실제 브랜치명 15곳 | 가명 `work_s`로 치환 (`a990d58`) |

**남은 문제: git 이력에는 제거 전 내용이 그대로 보존된다.** 공개 저장소라 과거 커밋(`5d47ab5` 등)을 열면 지금도 볼 수 있다. 완전 제거는 이력 재작성 + 강제 푸시가 필요해 **하지 않기로 두었다**(강제 푸시는 작업 지침상 금지 대상).

**Why:**
- 과거에 `baae0f5`(프로젝트 고유명 익명화), `036ca62`(sanitize git docs) 커밋으로 이미 익명화를 시도했는데도 남아 있었다. 한 번의 일괄 치환으로는 안 잡히고 재발한다.

**How to apply:**
- 새 노트를 쓰거나 기존 노트를 고칠 때 `grep -rn -i "<사내 식별자>" --include="*.md" content/`로 확인한다.
- 오탐 주의: `quartz/util/emojimap.json`(업스트림 이모지 맵)이 문자열 우연 일치로 잡힌다. `content/` 하위만 보면 된다.
- 다른 노트의 `10.10.10.10`·`gitid`·`10.0.0.5`는 실제 값이 아니라 이미 익명화된 예시값이다. 건드릴 필요 없다.
