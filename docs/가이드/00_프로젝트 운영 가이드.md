# Jintae Brain 프로젝트 운영 가이드

> 실행·배포 방법은 [README.md](../../README.md)를 참고한다. 이 문서는 **내부 운영 상세**에 집중한다. 기준일 2026-09-17.

## 1. 프로젝트 목적
- Markdown 기반 개발 공부 문서를 누적 관리.
- 위키링크(`[[문서명]]`) 기반 지식 연결(백링크) 강화.
- GitHub Pages 정적 사이트 운영 — **공개** 사이트라 회사 내부 정보를 싣지 않는다([AGENTS.md](../../AGENTS.md) 콘텐츠 규칙).

## 2. 환경 / 스택 상세
- 프레임워크: Quartz v4 (`package.json` 4.5.2)
- 런타임: Node.js 22 (`.node-version` = v22.16.0)
- 로컬 실행: **로컬웹** `npx quartz build --serve`, 포트 `8080`. `content/`·`quartz.config.ts`·`quartz.layout.ts`·`quartz/` 안의 `.ts`/`.tsx`/`.scss` 변경을 감시해 자동 리빌드한다.
  - Docker 파일(`docker-compose*.yml`·`Dockerfile`·`.dockerignore`)은 **보존용**이며 일상 미리보기엔 쓰지 않는다. 2-모드 구조 설명은 노트 [Quartz Docker 2-모드 운영 구조](../../content/개발/프로젝트/Quartz%20Docker%202-모드%20운영%20구조.md).
- 호스팅: GitHub Pages + GitHub Actions (`.github/workflows/deploy.yml`, `main` push 시 자동)
- 로케일: `ko-KR` / baseUrl: `jintae-choi.github.io/Jintae_Brain`
- 디자인: **단일 디자인**(테마 스위처 A/B/C는 커밋 `dabf4be`에서 제거). 폰트(Google Fonts): 본문 IBM Plex Sans KR, 헤더·코드 JetBrains Mono. 팔레트·타이포는 `quartz.config.ts`의 `theme`, 커스텀 스타일은 `quartz/styles/custom.scss`.
- 주요 기능: SPA, Popover, Backlinks, Graph View, KaTeX, Syntax Highlighting

## 4. GitHub CLI (gh) — PR 워크플로우

> `gh` v2.90.0 설치 완료 (2026-04-22). 인증: `jintae-choi` 계정 / HTTPS / keyring 저장.

### 기본 명령

```powershell
# 인증 상태 확인
gh auth status

# 리포 정보
gh repo view

# PR 목록 (최근 10개)
gh pr list --state all --limit 10
```

### PR 생성 표준 패턴

```powershell
# 브랜치 push 후 PR 생성
git push -u origin feat/my-feature

gh pr create \
  --title "feat: 기능 요약 (70자 이내)" \
  --base main \
  --body "$(cat <<'EOF'
## Summary
- 변경 내용 bullet

## Test plan
- [ ] 로컬웹 확인 (npx quartz build --serve → http://localhost:8080)
- [ ] 빌드 에러 없음
EOF
)"
```

### 자주 쓰는 명령

```powershell
gh pr view          # 현재 브랜치 PR 상태 확인
gh pr merge         # PR 머지 (기본: squash)
gh pr checkout 4    # PR 번호로 브랜치 체크아웃
gh pr diff          # PR diff 보기
```
