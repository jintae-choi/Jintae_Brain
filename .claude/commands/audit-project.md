# audit-project

프로젝트 품질을 3축으로 감사한다. `/review-note`가 노트 1개를 검사한다면, 이 명령은 프로젝트 전체를 검사한다.

## 실행

1. 인자 `$ARGUMENTS` 검증. 값이 `env|docs|content|(빈 값)` 중 하나가 아니면 아래 표를 안내하고 종료.
2. 아래 표에 따라 전용 감사 에이전트를 호출한다. 점검 대상·판단 기준·출력 포맷은 **각 에이전트 정의에 자체 포함**돼 있으므로 호출 프롬프트는 "정의대로 감사 수행"만 지시한다.
3. 모든 에이전트 응답을 받은 뒤 아래 "결과 종합 포맷"에 맞춰 사용자에게 보고한다.

| 인자 | 호출 방식 | 에이전트 |
|---|---|---|
| (생략) | 단일 메시지에서 **병렬** 호출 | `env-auditor` + `docs-auditor` + `content-auditor` |
| `env` | 단독 호출 | `env-auditor` |
| `docs` | 단독 호출 | `docs-auditor` |
| `content` | 단독 호출 | `content-auditor` |

각 에이전트 정의는 [.claude/agents/](../agents/) 하위 동명 파일 참조.

## 결과 종합 포맷

에이전트 리포트의 섹션별 태그(OK/개선/과함/부족)를 **축소하지 말고 그대로 유지**한다. 이 명령의 역할은 3축 결과를 이어 붙이고 종합 Top 3을 뽑는 것뿐이다.

```
## 1. .claude 환경 (env)
(env-auditor 리포트 본문 — 섹션별 태그 포함)

## 2. 프로젝트 문서 (docs)
(docs-auditor 리포트 본문 — 문서별 평가 포함)

## 3. 학습노트 (content)
(content-auditor 리포트 본문 — 전체 통계 + 우선 정리 TOP-5 포함)

## 종합 우선순위 Top 3
1. ...
2. ...
3. ...
```

- 각 파일/노트 경로는 markdown 링크 `[파일명](상대경로)` 형식.
- 단일 축 호출 시 해당 섹션과 종합 Top 3만 출력.
- 사용자에게 보고하는 메인 메시지 전체 길이는 600단어 이내.

## 제약

- **파일 수정 금지**. 이 명령은 감사·제안 전용이다. 수정이 필요하면 사용자가 승인한 뒤 `/polish-note`·`/add-terms` 등 별도 명령으로 진행한다.
- 메인 컨텍스트에서 직접 파일을 광범위하게 읽지 않는다. 반드시 전용 감사 에이전트에 위임한다(토큰 보호).
- `quartz/`, `public/`, `node_modules/`는 절대 보지 않는다.
