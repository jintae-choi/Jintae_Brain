### 1-1. 큰 그림

개념의 전체 아키텍처·파이프라인을 다이어그램으로 먼저 보여준다. 세부는 나중.

```
[A] ──► [B] ──► [C]
         │
         ▼
        [D]
```

### 1-2. 사전 지식 / 용어

본문 이해에 필요한 기반 개념·용어를 짧게 정리한다. 독자가 이미 알면 스킵하라고 명시.

- **용어 A** — 한 줄 정의. 필요시 비유·예시.
- **용어 B** — 한 줄 정의.

## 2. 전체 예시 코드

완성된 코드/명령어 전체를 먼저 제시한다. 조각이 아니라 "돌아가는 완성품"이 중요.

```bash
#!/bin/bash
# 실제 사용하는 명령어 또는 코드
```

## 3. 라인별 / 포인트별 상세 해설

위 코드의 각 구간을 잘라 전문용어·옵션·플래그 단위로 해설.

### 3-1. 환경 변수 / 초기 설정

```bash
VAR="value"
```

| 항목 | 설명 |
|---|---|
| `VAR` | ... |

### 3-2. 핵심 로직

```bash
command --flag arg
```

- `command` — 설명
- `--flag` — 설명
- `arg` — 설명

> **용어박스: 핵심 용어**  
> 낯선 전문용어가 나오면 인용 블록으로 분리해 설명.
